# daily-scrum

매일 아침 반복하는 스크럼 업무 준비를 한 번에 끝낸다.

1. `NEMO-APS365` 프로젝트의 템플릿 "스크럼 업무 작성 양식"으로 `YYMMDD 오전 스크럼` 업무를 생성한다 (담당/참조/태그/본문이 템플릿 그대로).
2. 제목 날짜 기준 직전 스크럼(전날, 없으면 가장 최근)에서 내가 쓴 마지막 댓글을 찾아 새 업무에 댓글로 붙여넣는다. 사용자는 Dooray에서 이 댓글을 오늘 내용으로 고치기만 하면 된다.

## 실행

모든 로직은 스크립트에 있다. 직접 curl로 재구현하지 말고 스크립트를 쓴다.

```bash
python3 <이 스킬 디렉터리>/scripts/daily_scrum.py            # 오늘(KST) 날짜
python3 <이 스킬 디렉터리>/scripts/daily_scrum.py --date 260917   # 특정 날짜
python3 <이 스킬 디렉터리>/scripts/daily_scrum.py --dry-run     # 생성 없이 계획과 복사될 댓글만 확인
```

- 날짜는 `YYMMDD` 6자리다. 사용자가 "내일", "9월 17일"처럼 말하면 KST 기준으로 변환해 `--date`로 넘긴다.
- 사용자가 "확인만", "뭐가 복사되는지 보여줘"처럼 미리 보고 싶어하면 `--dry-run`을 먼저 돌린다. 그 외에는 바로 실행한다. 스크립트가 중복 생성과 중복 댓글을 스스로 막으므로 다시 실행해도 안전하다.

## 스크립트 동작

| 상황 | 처리 |
|---|---|
| 같은 제목의 스크럼이 이미 있음 | 새로 만들지 않고 그 업무에 댓글만 복사 |
| 새 스크럼에 이미 내 댓글이 있음 | 댓글 복사를 건너뜀 |
| 직전 스크럼에 내 댓글이 없음 | 업무만 생성하고 댓글은 건너뜀 (사용자에게 알린다) |
| `DOORAY_API_TOKEN` 없음 / 401 | `/dooray-setup`으로 먼저 인증을 끝내고 다시 실행 |
| 프로젝트나 템플릿을 못 찾음 | 템플릿 이름이나 프로젝트 코드가 바뀌었을 수 있다. 스크립트 상단 상수(`PROJECT_CODE`, `TEMPLATE_NAME`)를 사용자와 확인 |
